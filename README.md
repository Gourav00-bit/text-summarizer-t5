# Text Summarizer using T5

An abstractive text summarization project built with Python, Jupyter Notebook, Hugging Face Transformers, and the T5-small model. The project uses the SAMSum dialogue summarization dataset.

## Features
- Transformer-based text summarization
- Notebook-based model experimentation
- Dialogue summarization using SAMSum
- Model training and evaluation experiments

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- T5-small
- Pandas
- Jupyter Notebook

## Dataset
The notebook uses the SAMSum dataset, with the following expected files:
- `samsum-train.csv`
- `samsum-validation.csv`

Keep dataset files out of GitHub unless you have confirmed the redistribution terms and intend to publish them.

## Installation
1. Clone the repository:
   `git clone https://github.com/YOUR_USERNAME/text-summarizer-t5.git`

2. Open the project folder:
   `cd text-summarizer-t5`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Start JupyterLab:
   `jupyter lab`

5. Open `text_summarizer.ipynb` and run the notebook cells.

## Notes
- Check local file paths before running the notebook.
- Training time depends on your hardware.
- Model checkpoints and generated files should not be committed unnecessarily.
- Review dataset licensing before redistribution.
